# Bubble Knight: Cleansing Crusade

Welcome to **Bubble Knight: Cleansing Crusade**, a game created during the Global Game Jam 2025. Dive into an epic adventure, bursting bubbles and cleansing the lands in this fast-paced, whimsical journey!

## Installation and Playing the Game

We have two versions of the game available for you:

### **1. Windows Installation Version**
- Download the Windows release of the game from the [Releases page](https://globalgamejam.org/games/2025/bubble-knight-cleansing-crusade-6).
- Extract the ZIP file to your desired location.
- Double-click on `BubbleKnight.exe` to launch the game.
- Enjoy the adventure!

### **2. WebGL Release**
- If you'd like to play directly in your browser, visit our WebGL release hosted on [itch.io](YOUR_ITCH_IO_LINK).
- No installation required – simply click the "Play" button and start your journey!

## About the Game

**Bubble Knight: Cleansing Crusade** was developed as part of the [Game Jam Barcelona @ UPC](https://www.gamejambcn.com/Home/About), an official event of the **Global Game Jam 2025**. This jam challenges developers to create a complete game within 48 hours based on a global theme. Hundreds of participants worked simultaneously around the world to create innovative games!

Our game draws inspiration from the rapid prototyping and creative atmosphere fostered during the jam. We hope our entry provides you with as much joy as we had while developing it!
